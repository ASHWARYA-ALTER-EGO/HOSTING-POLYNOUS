# \# 🧠 POLYNOUS — "Many Minds, One Answer"

# 

# A production-grade multi-agent AI research platform where 7 specialized AI agents collaborate to research, analyze, debate, and deliver comprehensive answers with citations and confidence scores.

# 

# \## 🤖 The 7 Agents

# 

# \### Research Mode

# \- 🔍 \*\*Search Agent\*\* — Finds relevant web + academic sources

# \- 📝 \*\*Summariser Agent\*\* — Condenses each source to key points

# \- 🔎 \*\*Critic Agent\*\* — Checks contradictions, assigns confidence

# \- ✍️ \*\*Writer Agent\*\* — Assembles final cited answer

# 

# \### Debate Mode

# \- 🟢 \*\*FOR Agent\*\* — Argues supporting position

# \- 🔴 \*\*AGAINST Agent\*\* — Argues opposing position

# \- ⚖️ \*\*Judge Agent\*\* — Evaluates and declares winner

# 

# \## 🚀 Features

# \- Real-time streaming responses

# \- Confidence scoring (0-100%)

# \- Debate mode with AI judge

# \- Clickable source citations

# \- Neural network animated background

# \- Glassmorphic dark UI

# \- Mobile responsive

# 

# \## 🛠️ Tech Stack

# \- \*\*Backend:\*\* FastAPI + LangGraph + Anthropic Claude

# \- \*\*Frontend:\*\* React + Vite

# \- \*\*Search:\*\* Tavily API

# \- \*\*Vector DB:\*\* Pinecone

# \- \*\*AI:\*\* Claude 3 Haiku
